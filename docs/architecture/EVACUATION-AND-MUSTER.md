# Evacuation Planning & Muster Accountability

## Mechanics
- **Evacuation Snapshot**: Captures expected unit occupants and on-site staff/visitors at order time.
- **Presence Statuses**: `NOT_CHECKED`, `SAFE_AT_MUSTER`, `SAFE_ELSEWHERE`, `EXITED`, `NOT_ON_SITE`, `UNACCOUNTED`.
- **Conflict Resolution**: Conflicting status updates from concurrent responders create audit-tracked review entries without silent overwrites.
