# Governed Semantic Metric Layer

## Core Metrics
- `finance.collection_efficiency`: $\frac{\text{Collected Amount}}{\text{Billed Amount}} \times 100$
- `helpdesk.sla_compliance`: $\frac{\text{Tickets Resolved Within SLA}}{\text{Total Resolved Tickets}} \times 100$
- `assets.critical_down`: Count of high/critical operational assets in breakdown status.
- `utilities.electricity_kwh`: Total aggregate smart meter consumption.
