# Enterprise Utilities Domain Architecture

## Bounded Context
- **Services**: Electricity, Water, Gas, DG Backup, Solar Generation, STP, WTP.
- **Supply Sources**: Grid Substation, Borewells, Municipal Mains, Water Tankers, Generators, Solar Inverters.
- **Topology**: Source Inflow $\rightarrow$ Storage Sump $\rightarrow$ Main Meter $\rightarrow$ Distribution $\rightarrow$ Unit Sub-Meter $\rightarrow$ Consumption $\rightarrow$ STP Treatment $\rightarrow$ Recycled Water Reuse.
